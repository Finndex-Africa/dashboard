# Internationalization (English / French)

The dashboard and the public frontend share one i18n setup, documented in full
in the frontend repo:

    ../frontend/docs/i18n.md

## Dashboard-specific summary

- Locale is **not** in the URL. It lives in the `NEXT_LOCALE` cookie, set by a
  server action (`src/i18n/actions.ts`) so the existing auth middleware in
  `src/middleware.ts` is untouched.
- Config: `src/i18n/routing.ts` (locale list) and `src/i18n/request.ts`
  (reads the cookie, loads `messages/<locale>.json`).
- Switcher: `src/components/global/LanguageSwitcher.tsx`, rendered in the
  sidebar footer, the mobile drawer, and Settings → Language.
- Antd's built-in strings (pagination, empty states, date pickers) are set via
  `ConfigProvider locale` in `src/components/LayoutClientWrapper.tsx`.
- Because there is no locale prefix, keep using `next/link` and
  `next/navigation` here — the `@/i18n/navigation` wrapper is frontend-only.

## Coverage

All 39 dashboard files are translated: admin dashboard, properties, services,
buy-sell, advertisements, users, verifications, bookings, notifications,
messages, user reports, notify-me, profile, chat, plus every form and table.

Namespaces are split by role so a component only pulls what it needs:

| Namespace | Holds |
|---|---|
| `common` | verbs and statuses reused everywhere (Approve, Reject, Pending…) |
| `nav`, `nav2` | sidebar items and back/go-to links |
| `home` | admin dashboard widgets |
| `listing` | listing/review screens shared by properties, services, buy-sell |
| `form`, `placeholder` | field labels and input placeholders |
| `toasts`, `errors2` | success and failure messages |
| `filters`, `misc`, `reviews2`, `roles`, `status` | the rest |

Components declare one hook per namespace they use, named `t_<namespace>`:

```tsx
const t_common = useTranslations("common");
const t_toasts = useTranslations("toasts");

<Button>{t_common("approve")}</Button>
message.success(t_toasts("propertyApproved"));
```

`config/navigation.tsx` has **zero importers** and was skipped — delete it or
translate it if it is revived.

## Adding a string

```jsonc
// messages/en.json + messages/fr.json — both must have the key
"users": { "inviteButton": "Invite user" }
```

```tsx
const t = useTranslations("users");
<Button>{t("inviteButton")}</Button>
```
